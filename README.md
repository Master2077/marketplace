# Проект MarketPlace

## Описание:

Учебный интернет-магазин с тёмным интерфейсом, который постепенно развивается
в маркетплейс. Сейчас это семь свёрстанных страниц и Django-сервер с маршрутизацией
и формой обратной связи. Реальной оплаты, доставки и авторизации пока нет.

Реализовано:

- `home` — главная страница: продавцы и популярные товары
- `catalog` — каталог продавцов с категориями и сортировкой
- `favorites` — избранное: 3 товара и 3 продавца
- `orders` — корзина с группировкой по продавцам и история из 4 заказов
- `user_profile` — профиль покупателя: Александр, 3 покупки, 3 избранных
- `seller` — страница автора: обложка, аватар, рейтинг, статистика и товары
- `contacts` — форма обратной связи: проверка полей, CSRF, сохранение в SQLite
  и сообщение об успешной отправке
- `ContactMessage`, `ContactForm` — модель и форма для сообщений с контактов
- `app.py` — отдельный учебный сервер на `http.server`: GET отдаёт страницы,
  POST печатает данные формы в консоль
- `css/common.css` и `css/<страница>.css` — общие стили и стили страниц

## Установка:

1. Клонируйте репозиторий (рабочая ветка — `develop`):

```
git clone -b develop https://github.com/Master2077/marketplace
cd marketplace
```

2. Создайте виртуальное окружение и установите зависимости:

```
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install django python-dotenv
```

3. Задайте секретный ключ:

```
$env:DJANGO_SECRET_KEY = "ваш-ключ"
```

4. Примените миграции:

```
python manage.py migrate
```

## Использование:

1. Запустите сервер:

```
python manage.py runserver
```

2. Откройте страницы:

- `http://127.0.0.1:8000/` или `/index.html` — главная
- `/catalog.html` — каталог
- `/favorites.html` — избранное
- `/orders.html` — заказы
- `/profile.html` — профиль
- `/seller.html` — страница автора
- `/contacts.html` — контакты
- `/admin/` — админка (нужен `createsuperuser`)

3. Заполните форму на странице контактов: сообщение сохранится в базе,
   в браузере появится «Сообщение отправлено», а запись будет видна в админке.

4. Старый учебный сервер запускается отдельно и тоже использует порт 8000:

```
python app.py
```

## Тестирование:

Автотестов в проекте пока нет. Проверка выполняется вручную:

- `python manage.py check` — проверка настроек Django;
- открытие всех страниц и проверка кода ответа 200;
- отправка формы: валидные данные создают запись, невалидные — нет;
- просмотр сообщений в админке.

В дальнейшем планируется добавить тесты на pytest.
